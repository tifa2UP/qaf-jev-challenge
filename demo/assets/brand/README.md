# Qaf brand assets

The Qaf logomark and wordmark are original Qaf brand artwork, used for this competition submission at the project owner’s request. Their proportions and paths are unchanged. Monochrome variants use Qaf’s foreground colors. Brand artwork remains the property of Qaf and is excluded from this repository’s code license.

IBM Plex Sans Arabic and Inter are the production typefaces used by Qaf. Font files remain under their SIL Open Font License 1.1 terms: see OFL.txt for IBM Plex and Inter-OFL.txt for Inter. IBM Plex Sans Arabic is Qaf’s pinned revision 1.101, from the Google Fonts distribution. Inter’s license source is https://github.com/rsms/inter/blob/master/LICENSE.txt.

Only visual brand artwork and font assets are included here. No Qaf application source, prompts, corpus or user data is included.
